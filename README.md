# JamaAlca AI-Powered Farming App

🌿 Description
-------------
JamaAlca is an AI-powered farming application designed to help Jamaican farmers optimize their agricultural practices. The app combines real-time weather monitoring, plant disease detection, and community knowledge sharing to improve farming outcomes.

🚀 Features
----------
- 🔍 AI-powered plant disease detection
- 🌤️ Real-time weather monitoring and alerts
- 👨‍🌾 Community forum for farmer knowledge sharing
- 📱 User-friendly mobile interface
- 🤖 AI-driven treatment recommendations
- 📊 Farm analytics and insights

⚙️ Project Structure
------------------
- `screens/`: UI components and screen layouts
- `services/`: Backend services (weather, disease detection, etc.)
- `utils/`: Utility functions and helpers
- `models/`: Data models and structures
- `assets/`: Static files and resources

🛠️ Setup & Installation
---------------------
1. Clone the repository:
   ```
   git clone https://github.com/jennisha876/JamaAlca.git
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Run the application:
   ```
   python jamaalca.py
   ```

📚 Dependencies
-------------
See `requirements.txt` for a complete list of dependencies.

🔧 Configuration
-------------
- Azure Vision API credentials required for plant disease detection
- OpenAI API key needed for treatment recommendations
- Internet connection required for weather data
